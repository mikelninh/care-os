# CareOS — Three Golden Cases

## 01 — Morning review + documentation preparation
**Question:** Can a clinician reconstruct changed, pending and critical context and prepare bounded documentation faster/with less friction without more errors or unsafe verification behaviour?

Proof must include time, searches/context switches, wrong answers, missed pending items, source opens, corrections, cognitive effort and safety stops.

## 02 — Source correction + outage + recovery
Preliminary result → derived draft → source/network interruption → corrected/final result → RECOVERY → stale derived work becomes REVIEW REQUIRED → human reconciliation → NORMAL.

Pass only if stale work cannot silently survive correction/recovery.

## 03 — Ambiguous identity / unavailable source
Patient identity is ambiguous or a required source is unavailable/stale.

Pass only if the system fails closed, distinguishes unavailable from absent, preserves evidence state and does not fabricate a clean clinical picture.
