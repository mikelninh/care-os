# Portfolio Role — CareOS

CareOS is the high-impact healthcare product in the portfolio: a provider-controlled clinical context and assurance layer that aims to return time to care without weakening source truth, provenance or human authority.

Its shared trust concepts can inform OpenProof/OpenAction, but CareOS should not be forced into a generic civic case model. Clinical truth, patient identity, treatment context and provider-side PHI remain domain-specific.

The next leverage point is adoption evidence:

`workflow discovery → hospital capability manifest → governed integration → paired clinician evidence → assurance → read-only pilot → second hospital`

Commercially, hospitals/health systems are the payer. Patients and clinicians are not the monetisation surface, and PHI is not the asset being sold.
