# CareOS Commercial Metrics

CareOS commercial success must remain subordinate to clinical safety and trustworthy information use.

## Value metrics

- clinician task time returned;
- systems/searches/context switches avoided;
- source-retrieval friction;
- documentation preparation time;
- integration effort per hospital/vendor;
- repeatability from hospital #1 to hospital #2.

## Mandatory counter-metrics

- wrong answers;
- missed pending/critical items;
- provenance/source-open behavior;
- corrections;
- acceptance without source verification;
- safety stops;
- privacy/security findings;
- clinician cognitive effort.

A speed/cost improvement is not a commercial win if these safety measures worsen materially.
