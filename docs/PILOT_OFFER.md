# CareOS Workflow Proof Sprint — Initial Offer

A paid pre-production evidence engagement for hospitals that want to test one workflow without buying an unproven clinical AI product.

## Scope

One workflow family, initially physician morning review + documentation preparation.

## Deliverables

- baseline workflow map and measurement plan;
- hospital capability/source manifest;
- integration feasibility map;
- privacy/security/authority boundaries;
- synthetic/deidentified clinician evaluation where approved;
- provenance and safety-stop analysis;
- evidence ledger;
- final go / blocked / next-proof recommendation.

## Initial commercial hypothesis

**€4,900–€9,900 fixed fee** depending on workflow complexity and permitted access.

The price is a hypothesis to validate in buyer conversations, not established market pricing.

## Promise

The hospital is buying disciplined evidence and integration learning. It is **not** buying a claim that CareOS is clinically validated or production-ready.

A negative result is still a valid deliverable if the sprint clearly shows why the workflow should not graduate.
