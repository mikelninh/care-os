# ADR-004 — AI/models are untrusted proposers, not truth authorities

**Status:** Accepted  
**Date:** 2026-08-16

## Context

LLMs and document models can extract useful structure but can also hallucinate, paraphrase evidence, invent chronology or resolve conflicts without sufficient basis.

## Decision

Model output is an untrusted candidate. It may only enter the clinical truth layer after mechanical evidence verification and downstream schema/identity/temporal/terminology/reconciliation controls.

Models may not directly write trusted facts, determine patient identity, invent effective dates, or silently choose winners between contradictory sources.

## Consequences

- model vendor can change without redefining clinical truth;
- model outage degrades extraction but not the core data contract;
- exact source evidence is required;
- model confidence is not clinical authority;
- deterministic/review layers remain downstream.

## Rejected alternative

Treat the LLM response as the clinical summary and trust citations generated by the same model.
